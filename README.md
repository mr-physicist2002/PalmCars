# PalmCars

A cinematic, responsive concept website for a performance-car showroom. The
project combines full-bleed photography, smooth section transitions, an
interactive model slider, colour selection, and a gallery-focused layout.

[View the live site](https://mr-physicist2002.github.io/PalmCars/)

## Highlights

- Responsive single-page presentation
- Interactive vehicle slider and colour controls
- Motion, parallax, and reveal effects with reduced-motion support
- Keyboard-friendly navigation and semantic page sections
- Static deployment with no build step

## Run locally

Open `index.html` directly, or serve the directory with any static web server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Structure

```text
index.html          page content and showroom sections
css/styles.css      layout, typography, and motion
js/main.js          slider, navigation, and interaction logic
assets/img/         vehicle photography and source notes
```

PalmCars is a portfolio concept and is not affiliated with the vehicle brands
shown in the demonstration.
